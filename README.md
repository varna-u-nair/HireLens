# 🔎 HireLens

### See the gap. Sharpen the skill. Nail the interview.

HireLens is an AI-powered career preparation tool that helps students understand how well their skills match a job and prepare for interviews.

## 🚀 Features

- 📄 Upload a resume in PDF format
- 💼 Paste a job description
- 🎯 Calculate skill match percentage
- ✅ Identify matched skills
- ❌ Identify missing skills
- 🤖 Get AI-powered skill-gap recommendations
- 🎤 Generate personalized interview questions
- 📝 Get AI feedback on interview answers

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini API
- PyPDF

## ⚙️ How It Works

1. Upload your resume.
2. Paste the job description.
3. HireLens extracts relevant skills.
4. The app compares resume skills with job requirements.
5. Gemini provides personalized skill-gap guidance and interview preparation.
